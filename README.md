Unsent: The Micro-Confession Sprint — a program that writes one text to `/output/entry.txt`: a two-part micro-confession, a `To:` line and the unsent line itself, written exactly as it was typed and never sent.

> To: Dad, who still sets two plates at dinner
> I moved Mum's pills to the top shelf the week before she fell, and I've rehearsed telling you every night since.

## Run it

```sh
python3 main.py
```
